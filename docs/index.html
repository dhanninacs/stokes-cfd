OpenFOAM 14  ·  Windows and Linux  ·  pre-alpha

An OpenFOAM GUI that goes from CAD to results in one window.

Stokes imports a STEP file, lets you click faces to set inlets, outlets and walls, meshes with snappyHexMesh or cfMesh, runs the solver and shows the flow. You never have to open a dictionary to get a case running, and every step can also be scripted.

What it does

A workbench, not a wrapper

The OpenFOAM case is generated from the model you build, so changing an inlet speed or a mesh size is an edit, not a hunt through dictionaries.

Geometry
STEP import through Open CASCADE. IGES and BREP from the command line.
Meshing
snappyHexMesh, blockMesh, cfMesh hex-dominant, tetrahedral and polyhedral, poly-hexcore. 2D planar and axisymmetric.
Physics
Laminar, k-ε and k-ω SST, with the energy equation. Parallel runs over MPI.
Results
Slices, clips, iso-surfaces, streamlines, vectors, probes, line plots, reports, picture export.
Units
Every value carries a unit. Type 2 [m/s] or U_in * 1.5.
Automation
The window, the stokes command and a local server share one API, so scripts and LLM agents can drive a case.

Install

Run it from source

You need Python 3.13 or 3.14, Node.js 22.12 or newer, Git, and OpenFOAM 14. The guides list every step and the usual snags.

Windows

OpenFOAM through FoamWin v14.0.0-win.5 or newer. MS-MPI for more than one core.

git clone -b windows https://github.com/dhanninacs/stokes-cfd.git
cd stokes-cfd
py -3.14 -m venv .venv
.venv\Scripts\pip install -e ".[agent,server,ui,cad,extract,explore,materials]"
cd web; npm install; npm run build; cd ..
.venv\Scripts\python -m stokes.app

Full Windows guide

Linux

The official openfoam14 package on Ubuntu 22.04 or newer, plus cfMesh if you want it.

git clone -b linux https://github.com/dhanninacs/stokes-cfd.git
cd stokes-cfd
python3.13 -m venv .venv
.venv/bin/pip install -e ".[agent,server,ui,cad,extract,explore,materials]"
cd web && npm install && npm run build && cd ..
source /opt/openfoam14/etc/bashrc && .venv/bin/python -m stokes.app

Questions

Common questions

Does it need WSL on Windows?

No. It drives FoamWin, a native Windows build of OpenFOAM 14, directly. There is no WSL, virtual machine or Docker layer.

Does it replace OpenFOAM?

No. You install OpenFOAM separately. Stokes writes the case, runs your OpenFOAM tools as separate processes and reads the results back. It never bundles or links OpenFOAM.

Can I use my own OpenFOAM cases?

You can import an existing case or one of the OpenFOAM tutorials, edit its files as text inside the app, and run it.

Can I run it on a remote machine?

Yes. Start python -m stokes.server there and open it through an SSH tunnel. The server only listens on 127.0.0.1 and needs a one-time token.
