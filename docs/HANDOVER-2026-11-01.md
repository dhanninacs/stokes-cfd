### Root cause established

Before this expansion, the schema listed only laminar and SST; the
incompressible writer accepted only laminar; the fluid writer accepted only
laminar/SST and rejected densities below 100 kg/m3 as gases. That threshold was
not a proper thermodynamic model. Snapshot boundary turbulence extraction was
conditional on exactly SST. A separate unbuilt SST pseudo-engine confused the
catalogue. These were application restrictions, not absence of OF14 models.
