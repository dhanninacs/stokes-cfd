Why Stokes

Modern and fast, natively

Shapr3D-style adaptive UI, STAR-CCM+ / Fluent tree. Python + C++ kernels, PySide6 + QML, VTK viewport. Follows your OS theme.

End to end, no dictionaries

STEP in → named faces → mesh → physics → run → scenes and reports. The case is compiled from one model; every number is reproducible.

Agent-ready from day one

One API behind the UI, CLI, HTTP server and MCP. Assistant with Claude, OpenAI, Gemini or a local model. Agents get full control.

Your OpenFOAM, your machine

Attaches to your existing OpenFOAM 14. In-house coupled solver built from source. Nothing leaves your machine.

Workflow

1Geometry

  • STEP, IGES, STL import
  • fluid extraction, enclosures, defeature
  • named selections by click, box, lasso, angle

2Mesh

  • snappyHexMesh, cfMesh, blockMesh, Gmsh
  • live cell estimate
  • quality tree, show bad cells

3Physics

  • steady or transient; laminar, RANS, LES
  • energy, CHT, porous, MRF
  • CoolProp, Cantera, REFPROP; units and expressions

4Solve

  • foamRun, foamMultiRun
  • coupledSimpleFoam: no relaxation factors
  • Fluent via PyFluent (Pro)

5Results

  • scenes, slices, iso, streamlines, probes
  • compare runs, HTML report (Pro)
  • open in ParaView
