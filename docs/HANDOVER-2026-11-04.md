## Running and debugging (learned the hard way)

- **FoamWin:** must be on a local disk. Its PowerShell handshake fails on a mapped
  drive. Environment: dot-source `of14-shell.ps1 -Quiet`, set
  `STOKES_FOAMWIN_ENV=<FoamWin>\of14-env.ps1`, `PYTHONPATH=<repo>;<repo>\agent`.
- **A server that "ignores" the client:** `py-spy dump --pid <server>`. The RPC
  dispatcher runs every command on the event loop, so one slow command holds
  every window.
- **Driving the page from scripts:** `?drive=1` in the URL exposes the zustand
  store as `window.__stokes`; `?debug=1` exposes `window.__stokesScene`.
- **A frozen app with `EGL_CONTEXT_LOST` / `0x887A0006`** in its console is a GPU
  reset. Look at what was just drawn: count draw calls and instances, not shaders.
